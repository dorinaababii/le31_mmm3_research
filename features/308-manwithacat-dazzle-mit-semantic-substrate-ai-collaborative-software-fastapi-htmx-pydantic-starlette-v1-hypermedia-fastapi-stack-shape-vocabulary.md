2. A `ai_agent_session` table (Alembic migration) with columns: `id` (UUID), `owner_id` (UUID FK to `User`), `started_at` (timezone-aware datetime), `ended_at` (timezone-aware datetime nullable), `proposed_queries` (JSON), `confirmed_queries` (JSON).
3. A `query_confirmation` table (Alembic migration) with columns: `id` (UUID), `session_id` (UUID FK to `ai_agent_session`), `proposed_query` (str), `confirmed_by` (str nullable), `confirmed_at` (timezone-aware datetime nullable), `executed_at` (timezone-aware datetime nullable), `result_count` (int nullable).
4. A `GET /v1/semantic-substrate/{entity_type}/{entity_id}` endpoint that returns the semantic-substrate record for the given entity.
5. A `POST /v1/semantic-substrate/{entity_type}/{entity_id}/update` endpoint that updates the semantic-substrate record (requires explicit owner confirmation; charter §3.4 *non-AI-fallback + human-gate* invariant).
6. A `POST /v1/ai-agent/sessions` endpoint that starts an AI-agent session.
7. A `POST /v1/ai-agent/sessions/{id}/confirm-query` endpoint that confirms a proposed query (charter §3.4 *human-gate* invariant).
8. A `GET /v1/ai-agent/sessions/{id}/results?query=<>&confirmed=<>&as_of=<>` query endpoint for confirmed query results.
