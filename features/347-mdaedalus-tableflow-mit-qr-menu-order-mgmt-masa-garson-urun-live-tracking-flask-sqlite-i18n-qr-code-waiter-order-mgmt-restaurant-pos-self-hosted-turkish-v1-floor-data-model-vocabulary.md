## Data model

N/A (defer artifact; vocabulary-only; no schema today).

When the first v1 PR that adopts the *order-as-sole-persisted-entity + table/garson/urun-as-lookup-columns + live-tracking-as-projection-over-order-state + i18n + multi-language + self-hosted + single-deploy* discipline lands, the schema is:

```sql
-- Order is the only persisted entity; table, garson, urun are lookup columns.
CREATE TABLE order (
    id BIGSERIAL PRIMARY KEY,
    table_id BIGINT NOT NULL,        -- lookup column (NOT a separate CRUD screen)
    garson_id BIGINT NOT NULL,       -- lookup column (NOT a separate CRUD screen)
    urun_id BIGINT NOT NULL,         -- lookup column (NOT a separate CRUD screen)
    quantity NUMERIC(10,2) NOT NULL,
    state TEXT NOT NULL,             -- 'draft' / 'sent_to_kitchen' / 'served' / 'paid'
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Live tracking is a projection over order state, NOT a dashboard feature.
CREATE VIEW live_tracking AS
    SELECT
        table_id,
        COUNT(*) FILTER (WHERE state = 'sent_to_kitchen') AS orders_in_kitchen,
        COUNT(*) FILTER (WHERE state = 'served') AS orders_served,
        MAX(updated_at) AS last_activity_at
    FROM order
    WHERE state IN ('draft', 'sent_to_kitchen', 'served')
    GROUP BY table_id;
```
