## Rollback path

- **Local revert**: `git revert <commit-sha>` then restart uvicorn.
- **Remote disable**: comment out the `bot.message.register(...)` call in
  `backend/app/main.py`. The bot reverts to the pre-feature-41 behaviour
  within one uvicorn reload.
- **Data retained**: the `StockEntry` rows written by the new path are
  append-only and remain in the ledger after a rollback. The handler
  accept rate is the only change.
- **Schema rollback**: the additive nullable `rationale` column is preserved
  after a code rollback (the column is nullable, so the old code path
  continues to write `rationale = NULL` rows). No DB migration rollback
  is needed.
